      Clearance levels

      Clearance decides who can open locked files. There are six levels. Give each one the Discord roles that should open it.

      i

      How it works: when a file is locked to a level, members with that level or any higher level can open it. A Level 4 role opens Level 4, 3, 2 and 1 files.

      You only need to add each role to its highest level. The server owner and members with Administrator permission can always open everything.

      Emergency protocols

      Keys for wiping this server's archive (Protocol Epsilon) and restoring it from backup (Omega Directive). Most servers never need these, and you can safely skip this page.

      ⚠ Classified: nuclear launch sequence

      Viewing these keys requires acknowledging that their use is irreversible.

      Protocol Epsilon: total destruction

      Epsilon keys authorize the complete and irreversible destruction of this server's archive. When executed:

      • All archived files are permanently deleted
      • All backups are purged
      • Every trace of this server's data is removed
      • There is no undo and no recovery

      These keys can destroy everything.

      Omega Directive: revival sequence

      Omega is a post-Epsilon restoration protocol. When activated:

      • The system restores from the latest available backup
      • Restoration fails only if no backup is available
      • Use only after Protocol Epsilon or a catastrophic failure

      Proceed only if you understand these protocols and accept full responsibility.

      Emergency keys

      Keys are stored per server. Generate fresh keys before sharing them with command staff. New keys only take effect after you save.
